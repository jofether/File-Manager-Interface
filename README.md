# File Manager Interface

A Vite + React + Tailwind CSS mock file manager focusing on breadcrumb navigation and a uniform file grid.

## Scripts
- `npm install` to install dependencies.
- `npm run dev` to start the dev server.
- `npm run build` to create a production build.
- `npm run preview` to preview the production build.

## Notes
- Breadcrumb separators currently include a placeholder span marked `FUTURE BUG` for training purposes.
